# EduLearn
EduLearn is a web-based application used for the efficiency of students, faculty and admin based on last-minute attendance tracking, prediction analysis, AI summarization, sticky notes generation, quiz maker, automated timetable generation and a lot more other features.

---

## 🚀 Features

### 👨‍🎓 Student Portal

- Real-time attendance tracking
- AI-powered concept summarization
- Sticky notes for every concept
- Performance dashboard
- Voice assistant for students

### 👩‍🏫 Faculty Portal

- Manage student attendance
- Manage schedules
- Monitor academic performance
- Track student progress

### 👨‍💼 Admin Portal

- Monitor campus-wide metrics 
- Centralized academic management
- Student progress overview

---

## 💡 Problem Statement

Educational institutions often rely on multiple disconnected platforms for attendance, communication, and academic tracking. This makes information scattered and difficult to manage. Also, students and teachers use different systems that don't work well together. This causes confusion and lack of transparency. Students can’t easily track their attendance or get help with studies, while teachers struggle with tasks like attendance, schedules and leave. Institutional leaders lack a unified dashboard to effectively monitor and manage overall campus operations.

EduLearn brings these essential services together into one centralized platform, making academic management easier for students, faculty, and administrators.

# ⚙️ Getting Started

## Clone the Repository

```bash
git clone https://github.com/Priyanshi305/EduLearn.git
```

Move into the project directory.

```bash
cd EduLearn
```

Install the dependencies.

```bash
npm install
```

Start the development server.

```bash
npm start
```

The application will run on:

```
http://localhost:3000
```
